## Gotchas & traps
- **No worktree isolation on Windows**: Agent tool with `isolation: "worktree"` fails with "core.worktree redirect" error. Always launch agents without isolation on this repo.
- **Parallel agents cause memory pressure**: Running 10+ Sonnet agents simultaneously can cause esbuild VirtualAlloc failures. Retry resolves it.
- **Webview scripts are inline template strings**: They cannot use TypeScript imports. JS-text generators (`escapeHtmlJs()`, `formatBytesJs()`) are the pattern for shared logic in webview client scripts.
- **extension/CHANGELOG.md and extension/README.md are generated copies**: A PreToolUse hook blocks edits. Always edit the root files.
- **The /finish skill expects to run per-task**: When fixing multiple bugs, run /finish after each one, not once at the end. The user's process expectation is per-bug reflection.
